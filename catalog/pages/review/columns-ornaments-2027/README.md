# پیش‌نویس چهار بخش ستون — کاتالوگ ۲۰۲۷

این ۲۴ صفحه صرفاً برای بازبینی هستند؛ تأیید نهایی هندسه یا چاپ نیستند. همهٔ ابعاد سانتی‌متر است. قالب و تصاویر همان نسخهٔ آماده‌شده‌اند؛ در این بسته هیچ طرحی بازسازی نشده است.

قطر داخلی CTB 30 هنوز قطعی نیست و با خط تیره مشخص شده است. پیشنهاد تغییر عمومی کدها هنوز اعمال نشده است.
